# PROYECTO_NEON_CENSO

Piloto de edición concurrente de capas vectoriales (QGIS + QField + PostGIS en Neon) con
control de acceso por fila, auditoría y tablero de avance, como evidencia para un
operativo nacional de fincas agropecuarias.

- Empezar por `CLAUDE.md` (reglas) y `ESPECIFICACION.md` (fases y criterios).
- Estado actual: `docs/sesiones/` (la más reciente).
- Por qué las cosas son así: `docs/DECISIONES.md`.
- Procedimiento completo y replicable: `docs/guia/Guia_replicacion_PostGIS.md`.

Credenciales: copiar `.env.example` a `.env` y completar. `.env` nunca se sube.
